# Example Posts (input for tone of voice)

Drop your **best, most representative** past content here as text files, then run
`/marketing-setup`. Quality matters more than quantity.

Suggested:
- 10–20 typical **Instagram captions** (English) → e.g. `ig-01.txt`, `ig-02.txt`, …
- 2–3 **newsletters / emails** (German) → e.g. `newsletter-01.txt`
- 1–2 **blog posts** (German), if available → e.g. `blog-01.txt`

`/marketing-setup` reads everything in this folder to derive the English and German
brand voice files. Pick examples that sound exactly how the brand should sound.
